Getting started

From install to first analysis

A short path to your first verified result. Detailed written and video tutorials are on the way.

1

Install & sign in

Download the Windows installer and sign in — OpenSees is bundled, no setup.

2

Build the model

Create a frame by hand, import a DXF, or describe it to the AI in plain language.

3

Load & analyze

Auto-generate seismic and wind loads, then run modal, RSA or Pushover.

4

Design & report

Run RC design with STRIX checks and export an editable PDF report.
