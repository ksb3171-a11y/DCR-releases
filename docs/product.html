Five analysis types, one solver

Linear static through nonlinear time-history — all driven by the OpenSees solver, with no TCL scripting and a responsive, cancellable run.

Analysis

Walls that behave correctly

Custom ASDShellQ4 shell elements eliminate the shear-locking that makes naive shells 16–19% over-stiff — wall demands track industry references within ±3%.

  • Custom ASDShellQ4 wall element — no shear locking
  • Automatic wall-structure load application
  • Precise plate analysis for wall-type buildings
  • Membrane / plate sub-types for correct out-of-plane behavior
