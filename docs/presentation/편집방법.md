# 발표덱 — 사용·편집 안내

이 폴더가 발표자료 전체입니다. **폴더째 USB에 복사해 가도 그대로 열립니다**(인터넷 불필요).
발표는 `index.html` 을 더블클릭해서 시작하면 됩니다.

---

## 1. 발표 중 키 조작 — PPT와 같습니다

| 하고 싶은 것 | 키 |
|---|---|
| **다음 장** | `→` `↓` `Enter` `Space` `PageDown` |
| **이전 장** | `←` `↑` `Backspace` `PageUp` |
| 처음 / 마지막 장 | `Home` / `End` |
| **개요** — 전체 슬라이드를 축소판으로 보고 클릭해 이동 | `O` |
| 전체화면 | `F` |
| **암전**(화면 끄기) — 아무 키나 누르면 복귀 | `B` |
| 인쇄 (A4 가로) | `P` |
| **편집 모드** | `E` (→ 8장) |

리모컨(프레젠터)의 앞/뒤 버튼은 `PageUp`/`PageDown` 을 보내므로 그대로 동작합니다.

## 2. 폴더 구조 — 무엇을 고치면 무엇이 바뀌나

```
docs/presentation/
├─ index.html            ← 로더. 고칠 일 거의 없음
├─ engine/               ← 화면·기능 (재사용 자산). 다음 발표에도 그대로 씀
│   ├─ deck.css   · deck.js       발표 (그리기 · 넘기기 · 인쇄)
│   └─ editor.css · editor.js     편집기 (내 PC에서 파일로 열 때만 켜짐)
├─ data/
│   ├─ deck.js           ← ★ 발표 내용. 슬라이드의 원본
│   ├─ verification.js   ← ⚠ 검증 수치. 자동 생성 — 손대지 마세요
│   └─ config.js         ← (구버전 잔재. 지금은 쓰이지 않습니다. 지우지 않고 남겨 둡니다)
├─ assets/
│   ├─ user/             ← ★ 직접 넣는 이미지 (여기가 항상 이깁니다)
│   └─ auto/             ← 자동 캡처 (user 에 같은 이름이 있으면 그쪽이 쓰입니다)
└─ _archive/             ← 이전 버전 보관 (이식 대조 검수에 씁니다. 지우지 마세요)
```

> **새 발표를 만들려면 이 폴더를 통째로 복사한 뒤 `data/deck.js` 만 갈아끼우면 됩니다.**
> `engine/` 은 손댈 일이 없습니다.

## 3. 슬라이드가 만들어지는 방식

슬라이드는 **1600×900 고정 캔버스**이고, 모든 요소가 그 안의 좌표에 놓입니다 — PPT 와 같은 방식입니다.
화면 크기가 달라지면 캔버스가 통째로 비례 확대·축소되므로,
**어느 PC·어느 해상도에서도 보이는 모습이 똑같습니다.** (해상도별로 따로 확인할 필요가 없습니다.)

`data/deck.js` 의 요소 하나는 이렇게 생겼습니다.

```js
{ id:'e3', type:'text', x:112, y:250, w:420, h:180, k:1,
  html:'<div class="card"><h3>제목</h3><p>내용</p></div>' }
```

| 항목 | 뜻 |
|---|---|
| `x, y` | 슬라이드 왼쪽 위에서부터의 위치 (픽셀) |
| `w, h` | 상자 크기 (이미지는 **"쓸 수 있는 최대 영역"** — 5장 참고) |
| `k` | 글자 배율. `1` 이 기본, `0.85` 면 그 상자 안의 글자·여백이 15% 작아집니다 |
| `html` | 내용 |

`type` 은 세 가지입니다 — `text`(글·카드·표) · `image`(이미지) · `vtable`(검증 표).

## 4. ⚠ 검증 수치는 손으로 고치지 마세요

검증 **21건 · 대조항목 131개**의 숫자는 `frontend/verification/records/*.json` 에서 **자동으로** 들어옵니다.

- 화면의 검증 표(13·14·16장, 부록 A)와 본문에 박힌 숫자는 전부 거기서 파생됩니다.
- 숫자를 바꾸려면 검증을 다시 돌려야 하고, 그러면 아래 명령 한 번으로 덱에 반영됩니다.

```bash
cd frontend
npm run deck:build      # records → data/verification.js 다시 굽기
```

**이 구조 덕분에 발표 자료의 숫자가 틀릴 수가 없습니다** — 같은 숫자를 두 곳에 적어 두지 않기 때문입니다.

## 5. 이미지 넣기

각 이미지 자리에 **파일 이름**이 적혀 있습니다 (예: `s10_app_full.png`).
그 이름 그대로 **`assets/user/`** 에 저장하고 새로고침(F5)하면 나타납니다. `.png` · `.jpg` 둘 다 됩니다.

- **`assets/user/` 가 항상 이깁니다.** 자동 캡처가 들어가 있는 자리라도 같은 이름으로 넣으면 바로 교체됩니다.
  `data/deck.js` 는 손댈 필요가 없습니다.
- **프레임이 그림 크기를 따라갑니다.** 가로로 긴 그림이든 세로로 긴 그림이든 테두리가 그림에 딱 붙고,
  뒤에 남는 여백이 생기지 않습니다. 자리는 정해진 영역의 **가운데**로 잡힙니다.
  → 그래서 편집기 오른쪽 패널의 `W`·`H` 는 **"쓸 수 있는 최대 영역"** 이고,
    실제로 보이는 크기는 그 위에 따로 적어 줍니다.
- 이미지 프레임의 핸들을 직접 끌기 시작하면 **현재 화면에 보이는 프레임이 편집 기준**이 됩니다.
  네 모서리는 그 프레임 비율을 유지하고, 상·하·좌·우 중앙은 폭과 높이를 독립적으로 바꿉니다.
- **그림을 프레임에 맞춤**을 누르면 현재 `X·Y·W·H`는 바꾸지 않고 그림을 프레임의 가로·세로에 맞게 늘립니다.
  이때 맞춤 선택도 `늘려 채우기`로 바뀌므로 빈 여백 없이 프레임 전체가 그림으로 채워집니다.
- 편집 모드에서 이미지를 **더블클릭**해 파일을 고르면 **선택 즉시 화면에 반영**됩니다.
  이어서 `assets/user/` 폴더를 **최초 한 번만** 지정하면 같은 슬롯 이름으로 영구 저장됩니다.
  브라우저가 이 폴더 권한을 기억하므로 권한이 유지되는 동안은 창을 닫았다 열어도 다시 묻지 않습니다.
  브라우저가 보안상 권한을 초기화한 경우에만 같은 폴더를 다시 승인합니다.
  폴더 지정을 취소해도 현재 화면의 미리보기는 유지되지만, 새로고침 후에도 남기려면 저장해야 합니다.
- 아직 안 넣은 자리는 `npm run deck:check` 가 **매번 목록으로 알려줍니다** — 빠뜨린 채 배포되지 않습니다.

## 6. 인쇄 · 배포

- `P` 키 또는 브라우저 인쇄 → **A4 가로, 슬라이드당 1페이지.** "배경 그래픽" 옵션을 켜세요.
- 인쇄는 흰 배경(라이트 테마)으로 자동 전환됩니다.
  화면 그대로(어두운 배경) 인쇄하려면 `data/deck.js` 의 `meta.printTheme` 을 `'screen'` 으로 바꾸세요.
- 홈페이지에 올릴 때는 이 폴더를 통째로 올리면 됩니다 (`_archive` · `_check` 제외).
  **편집기는 홈페이지에서 켜지지 않습니다** — 보는 사람에게는 아무 흔적도 보이지 않습니다.

## 7. 개발자용 명령 (frontend 폴더에서)

| 명령 | 하는 일 |
|---|---|
| `npm run deck:build` | 검증 기록 → `data/verification.js` |
| `npm run deck:check` | **검수** — 넘침 · 5개 해상도 · 인쇄 페이지수 · 텍스트 유실 · 이미지 출처 |
| `npm run deck:check-editor` | **편집기 검수** — 선택·이동·크기·되돌리기·잠금·저장 왕복 |
| `npm run deck:convert` | (1회성) 옛 흐름배치 덱 → 캔버스 덱 이식 |

> **`data/deck.js` 나 `engine/` 을 고쳤으면 반드시 `npm run deck:check` 를 돌리세요.**

## 8. 화면에서 직접 고치기 — 편집기

**`E` 키를 누르면 편집 모드**가 됩니다. 한 번 더 누르면 발표 화면으로 돌아갑니다.
(편집기는 **내 PC에서 파일로 열었을 때만** 켜집니다. 홈페이지에 올린 것에는 나타나지 않습니다.)

### 기본 조작

| 하고 싶은 것 | 방법 |
|---|---|
| **고르기** | 클릭 · `Shift`+클릭으로 여러 개 · 빈 곳을 끌면 범위 선택 · `Tab` 으로 차례차례 |
| **옮기기** | 끌기 · 화살표키 1px (`Shift`+화살표 10px) |
| **크기** | 테두리의 네모 핸들을 끌기 · **이미지 모서리 = 비율 유지** · 이미지 상하좌우 = 자유 변형 · 글상자 모서리+`Shift` = 비율 고정 |
| **글자 고치기** | **더블클릭** → 바로 타이핑. `Esc` 로 끝냄 |
| **글자 일부만 굵게·색** | 편집 상태에서 글자를 끌어 고른 뒤, 오른쪽 패널의 `굵게`·색 단추 |
| 되돌리기 / 다시 | `Ctrl+Z` / `Ctrl+Shift+Z` (50단계) |
| 복사 / 붙여넣기 / 복제 / 삭제 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` / `Delete` |
| 앞뒤 장 | 상단 `◀ 이전 장` / `다음 장 ▶` · `PageUp` / `PageDown` · 오른쪽 패널 맨 아래 **장 목록** 클릭 |
| 장 전체 관리 | `O` (아래 "장 관리") |
| **저장** | `Ctrl+S` — `data/deck.js` 에 그대로 씁니다 |

편집 모드를 유지한 채 장을 이동합니다. 이동 전에 현재 텍스트 편집은 자동으로 확정되고, 요소 선택만 해제되므로 다음 슬라이드를 곧바로 계속 편집할 수 있습니다.

- **끌면 분홍색 안내선**이 뜹니다. 다른 요소의 변·중심, 판면 여백, 화면 중심에 저절로 달라붙습니다.
  붙는 게 싫으면 `Alt` 를 누른 채 끄세요.
- 상자를 넘친 내용은 **빨간 테두리**로 표시됩니다. 위쪽 `전체 넘침 검사` 로 전 장을 한 번에 볼 수 있습니다.
  → **넘침은 가리지 않습니다.** 빨간 테두리가 뜨면 글을 줄이거나 상자를 키우세요.

### 만들고 지우기

위쪽 줄의 `＋글` `＋제목` `＋그림` `＋상자` 로 요소를,
`장 추가` `장 복사` `◀ 앞으로` `뒤로 ▶` `장 삭제` 로 슬라이드를 다룹니다.
새 장의 **챕터·그룹**을 오른쪽 패널에서 고르면 **번호와 목차가 저절로** 따라옵니다(손으로 쓰지 않습니다).

### 장 관리 — 개요 화면(`O`)

**`O`** 를 누르면 전체 슬라이드가 축소판으로 깔립니다. **편집 모드가 아니어도 바로 관리됩니다.**

| | |
|---|---|
| **고르기** | **한 번 클릭.** `Shift`+클릭 = 범위 · `Ctrl`+클릭 = 하나씩 더하기/빼기 · `Ctrl+A` 전체 |
| **그 장으로 가기** | **더블클릭** (개요가 닫히고 그 장이 나옵니다) |
| **순서 바꾸기** | **끌어다 놓기** (분홍 선이 들어갈 자리) · `◀ 앞으로` `뒤로 ▶` · 화살표키 `←` `→` |
| **삭제** | `Delete` |
| **복사 / 붙여넣기** | `Ctrl+C` / `Ctrl+V` · 잘라내기 `Ctrl+X` · 바로 복제는 `바로 복제` 단추 |
| 되돌리기 | `Ctrl+Z` |
| 저장 | `Ctrl+S` (고친 게 있으면 위쪽에 `저장` 단추가 나타납니다) |
| 닫기 | `O` 또는 `Esc` |

여러 장을 골라 한 번에 옮기고 복사하고 지울 수 있습니다. 전부 `Ctrl+Z` 로 되돌아갑니다.
목차·부록은 자동 생성이라 흐리게 표시되고 고를 수 없습니다.

> 이 관리 막대는 **내 PC에서 열었을 때만** 나타납니다. 홈페이지에 올린 것에는 없습니다.

편집 화면(개요가 아닌 곳)에서는 같은 `Ctrl+C` / `Ctrl+V` 가 **요소 단위**로 동작합니다.

### ⚠ 일부러 잠가둔 것

| 무엇 | 왜 |
|---|---|
| **검증 표**(`vtable`) | 표 전체가 `records/*.json` 에서 만들어집니다. **자리 옮기기·크기 조절은 됩니다.** |
| **문장 속의 검증 숫자** | 문장은 자유롭게 고칠 수 있습니다. **숫자 조각만** 잠깁니다 — 그 숫자는 검증 기록에서 옵니다. 실수로 숫자를 통째로 지우면 알려줍니다(`Ctrl+Z` 로 복구). |
| **목차 · 부록 A** | 슬라이드 목록과 검증 기록에서 **매번 다시 만들어집니다.** 고쳐도 다음에 열면 사라집니다. |

### 저장에 대해

`Ctrl+S` 를 처음 누르면 **기존 `data/deck.js`를 한 번 선택**합니다.
브라우저가 이 파일을 기억하므로 그다음부터는 저장 버튼만 누르면 **같은 파일에 바로 덮어씁니다.**
창을 닫았다 다시 열어도 파일 권한이 유지되면 바로 저장되며, 브라우저가 권한을 다시 요구할 때만 승인하면 됩니다.
(브라우저가 파일 쓰기를 지원하지 않으면 `deck.js`를 내려받으므로 기존 파일에 직접 덮어쓰세요.)

저장하지 않고 창을 닫아도 **편집 중이던 내용은 남습니다.** 다음에 열면 위쪽에
"저장하지 않고 닫은 편집 내용이 있습니다 — 복구 / 버리기" 가 뜹니다.
