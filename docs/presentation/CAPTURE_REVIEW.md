# 배포 전 캡처 위생 검수 체크리스트

> 이 발표자료는 **책자로 인쇄되고 홈페이지에 게시**됩니다.
> 한번 나가면 회수할 수 없으므로, 이미지에 실무 정보가 남아 있지 않은지 배포 전에 반드시 확인합니다.

---

## 왜 필요한가

캡처 화면에는 본인이 의도하지 않은 정보가 함께 찍힙니다.
특히 **실제 프로젝트 모델로 캡처할 때** 위험합니다.

기존 자동 캡처 하네스에도 같은 취지의 경고가 이미 달려 있습니다:

```
⚠ fixture 는 실모델이므로 리포 커밋 금지. 파일명 노출 캡쳐 없는지 배포 전 검수.
```

---

## 위험 구간 — 어디에 정보가 남는가

| 위치 | 무엇이 찍히나 | 확인 |
|---|---|---|
| **창 제목 표시줄** | 열려 있는 `.dcr` 파일 이름 (= 프로젝트명·발주처인 경우가 많음) | ☐ |
| **File 메뉴 · 최근 파일 목록** | 과거에 열었던 실무 파일 경로 전체 | ☐ |
| **좌측 모델 트리** | 실제 부재 부호, 층 이름, 타워 이름 | ☐ |
| **결과 범례 · 주석** | 하중조합 이름, 지진파 파일명 | ☐ |
| **상태 표시줄** | 파일 경로 · 저장 위치 | ☐ |
| **탐색기 · 다른 창** | 캡처 범위 밖으로 삐져나온 다른 프로그램 창 | ☐ |
| **작업표시줄** | 열려 있는 다른 문서 이름 | ☐ |

---

## 담당 구분

| 이미지 | 담당 | 위험도 |
|---|---|---|
| `assets/auto/` — 입력 UI 화면 | 자동 생성 | **낮음** — 샘플 모델 기반이라 실무 정보가 원래 없음 |
| `assets/user/` — 모델링 · 결과 화면 | 직접 캡처 | **높음** ← 이 체크리스트의 주 대상 |

---

## 배포 전 최종 확인

- [ ] `assets/user/` 의 모든 이미지를 **하나씩 열어** 위 7개 위치를 확인했다
- [ ] 창 제목에 실제 프로젝트 파일명이 없다 (있다면 캡처 전에 데모용 이름으로 저장 후 재캡처)
- [ ] 트리·범례에 발주처를 유추할 수 있는 이름이 없다
- [ ] 캡처 범위 밖의 다른 창·작업표시줄이 함께 찍히지 않았다
- [ ] 가로 1600px 이상이라 인쇄해도 흐리지 않다
- [ ] **인쇄 미리보기(P)로 전체를 한 번 넘겨보며** 이미지가 잘리거나 뭉개지지 않는지 확인했다

---

## 배포 형태별 추가 확인

| 형태 | 확인 |
|---|---|
| **현장 발표** | USB로 폴더째 복사해 **다른 PC에서 열어보기** · 인터넷 끄고 열어보기 · 리모컨 넘김 테스트 |
| **인쇄 책자** | `P` → 배경 그래픽 켜기 → A4 세로 · 표가 페이지 경계에서 잘리지 않는지 |
| **홈페이지 게시** | 커밋 전에 `assets/user/` 이미지들을 위 기준으로 재확인 (한번 push 되면 이력에 남음) |
