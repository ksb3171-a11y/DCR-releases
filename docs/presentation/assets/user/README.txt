파일이 없어도 발표자료는 정상 동작합니다.
그 자리에 "여기에 넣으세요" 안내 상자가 대신 표시됩니다.


── 캡처할 때 지켜 주실 것 ──────────────────────────────────────────────

1. 가로 1600px 이상으로 캡처해 주세요.
   그보다 작으면 책자로 인쇄할 때 흐리게 나옵니다.
   (앱의 Tools ▸ Capture 기능 또는 Windows 키 + Shift + S)

2. 실무 정보가 화면에 찍히지 않았는지 확인해 주세요.
   - 창 제목의 프로젝트 파일 이름
   - 최근 파일 목록
   - 좌측 트리의 실제 부재·층 이름
   - 결과 화면의 범례·주석에 적힌 발주처명
   → 배포되는 자료입니다. 자세한 내용은 CAPTURE_REVIEW.md 참고.

3. PNG 로 저장해 주세요. (JPG 도 되지만 글자가 번집니다)

4. 앱 화면은 어두운 배경이라 발표자료(어두운 배경)와 잘 어울립니다.
   화면 배율은 100% 로 두고 캡처하시면 글자가 가장 선명합니다.


── 파일 이름이 기억나지 않을 때 ────────────────────────────────────────

발표자료를 열면 이미지가 없는 자리에 점선 네모가 보입니다.
그 안에 필요한 파일 이름과 권장 크기가 그대로 적혀 있습니다.
